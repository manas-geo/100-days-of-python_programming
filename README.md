# 100 Days of Python Programming

A complete, step-by-step Python course in **100 Jupyter notebooks**, from the very basics to advanced topics, with a special focus on **Remote Sensing and GIS**.


- Python **3.10 or newer** is needed (for `match-case`). A few cells use Python 3.12+ features.
- Days 1 to 80 need only Python itself (a few days use `requests`, `flask`, `bs4` or `pytest`). Days 81 to 100 need the libraries in `requirements.txt`.
- Go in order, and **type the code yourself**.
